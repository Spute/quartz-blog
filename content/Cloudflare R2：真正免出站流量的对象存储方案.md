## 前言

Cloudflare R2 是一款 **兼容 S3 API 的全球对象存储服务**，其最突出的优势在于 **真正免出站流量（Egress）费用**。也就是说，无论你将数据分发到互联网还是提供给终端用户下载，都不会产生额外的带宽成本，这在对象存储领域非常少见，也使 R2 特别适合用于 **Web 静态资源托管、内容分发以及中大型文件服务**。

在调研对象存储方案时，发现了被不少开发者称为「赛博菩萨」的 Cloudflare 所提供的 R2 服务。其免费计划每月包含 **10 GB 的存储容量**，对个人项目、小工具或早期产品来说已经相当充裕；同时依托 Cloudflare 的全球基础设施，在稳定性和数据安全性方面也更让人放心。

---

## 💡 免费额度

Cloudflare 为 R2 的 **标准存储（Standard Storage）** 提供了明确且友好的免费额度，使得在项目早期或低负载场景下，几乎可以零成本使用：

|项目|免费额度|说明|
|---|---|---|
|存储空间|10 GB-month / 月|每月可免费使用 10 GB 的标准对象存储容量|
|Class A 操作|100 万次 / 月|包含对象创建、写入、列举等操作请求|
|Class B 操作|1000 万次 / 月|包含对象读取、查询等操作请求|
|出站流量（传输到互联网）|免费|数据从 R2 传输到公网不收取流量费用|

---

## 适用场景

- **个人开发者 / 独立项目**  
    小规模项目基本可以长期运行在免费额度内。
    
- **静态资源托管**  
    与 Cloudflare CDN 结合使用，几乎不需要为流量成本担心。
    
- **面向全球用户的应用**  
    免出站费用大幅降低跨区域访问和内容分发的成本。
