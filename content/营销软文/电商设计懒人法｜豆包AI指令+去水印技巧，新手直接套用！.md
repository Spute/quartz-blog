## 🧩 指令 1：同一产品，多种风格

👉 用途：快速出多版风格，选最优
```
保持产品主体不变，设计4种不同风格的电商宣传图，  
要求体现产品特点，适当加入辅助元素丰富画面，  
整体风格统一且具有高级感，不添加任何文字，  
高清画质，真实光影，商业摄影风格。
```


📌 重点提醒（很重要）：👉 一定要加：**“保持产品主体不变”**

不然AI很容易：改产品结构、改比例、甚至直接“换产品”。这一步能直接提升**80%稳定性**

## 🧩 指令 2：替换主体（超实用）

在日常电商素材替换中会很实用一比如相同系列的不同配色、不同型号的产品。

```
在保持整体场景、构图和风格不变的前提下，  
将画面中的产品替换为另一款同类型产品，  
要求尺寸比例真实，融合自然，光影一致，  
整体画面协调统一，高清质感。
```

👉 适合场景：快速制作产品衍生品。同系列产品 / 不同颜色 / 不同型号
