# holographic-sticker

一个 React 组件库，可以快速创建全息贴纸效果。

- 🎨 炫酷：支持类似全息卡片的折射与光影效果
- ⚡ 轻量：只需一行 npm install holographic-sticker
- 🛠 可定制：可自由修改图案、材质、光影参数
- 👩‍🎨 设计师友好：提供交互式编辑器，不写代码也能实时调试

在线预览 & 示例代码

- Demo: [https://holographic-sticker.vercel.app/](https://holographic-sticker.vercel.app/)
- Github: [https://github.com/LAWTED/holographic-sticker](https://github.com/LAWTED/holographic-sticker)
