## 摄影知识点

| 主题             | 要点总结                                                                                                                                                                    |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **相机直出 vs 后期** | 大部分相机照片需后期，手机直出更讨好（自动修图），特别的是富士人像直出优秀                                                                                                                                   |
| **品牌风格倾向**     | 富士：色彩好看、人像强；佳能：屏幕素质好；尼康：风光色彩真实；索尼：整体均衡                                                                                                                                  |
| **机身 + 镜头**    | 机身关注：画幅、CMOS 世代、屏幕素质；<br>镜头关注：光圈、焦段、成像、能否“喂饱机身”                                                                                                                         |
| **什么是单反？**     | 单镜头反光相机，光学取景 + 反光镜/五棱镜体积大，已逐渐退出市场，非单反（微单）是主流                                                                                                                            |
| **景深**         | 景深深：对焦点前后较大范围都处于清晰可接受范围，适合拍摄近景与远景都清楚的场景（如风光）。  <br>景深浅：对焦点前后清晰范围非常窄，只能让焦点附近的物体清晰，其他区域容易模糊（如人像）。<br>全画幅 > APS-C > 手机                                                     |
| **光圈**         | 光圈（Aperture）是相机镜头内部**可开可合的“可调节孔径”**，用来控制进入相机感光元件（CMOS/胶片）的**光线多少**。<br><br>你可以把它想象成：  <br>👉 _镜头里的“小窗户”，开大开小可调。_                                                        |
| **焦距**         | 焦距就是**镜头“看东西有多近/多远”**的能力。  <br>它决定了**视野范围**（宽不宽）和**画面放大的程度**（远不远）。<br><br>你可以把焦距理解成：  <br>👉 **镜头的“放大倍率” + “视角大小”的组合参数。**<br>焦距决定“拍多宽”和“拍多远”。  <br>焦距越短 → 越广；焦距越长 → 越近。 |



| 项目      | APS-C               | 全画幅           |
| ------- | ------------------- | ------------- |
| 传感器尺寸   | 小（22~24 × 14~16 mm） | 大（36 × 24 mm） |
| 画质      | 好，但高感表现略弱           | 更好，高感动态范围优秀   |
| 景深      | 较深，背景虚化弱            | 较浅，背景虚化强      |
| 焦距效果    | 有裁切系数（约 1.5~1.6×）   | 无裁切，镜头焦距真实    |
| 机身/镜头大小 | 小巧轻便                | 更大更重          |
| 价格      | 相对便宜                | 更贵            |

# 📌 **影响景深的四要素（必须牢记）**

1. **光圈**：越大（数字越小），景深越浅
    
2. **焦距**：越长（85mm、200mm），景深越浅
    
3. **拍摄距离**：越近，景深越浅
    
4. **画幅大小**：越大（全画幅 > APS-C > 手机），景深越浅
