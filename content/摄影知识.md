## 摄影知识点

| 主题                | 要点总结                                          |
| ----------------- | --------------------------------------------- |
| **相机直出 vs 后期**    | 大部分相机照片需后期，手机直出更讨好（自动修图），特别的是富士人像直出优秀         |
| **品牌风格倾向**        | 富士：色彩好看、人像强；佳能：屏幕素质好；尼康：风光色彩真实；索尼：整体均衡        |
| **购买核心：机身 + 镜头**  | 机身关注：画幅、CMOS 世代、屏幕素质；镜头关注：光圈、焦段、成像、能否“喂饱机身”   |
| **固定镜头组合**        | 每个机身通常都有几个常见优质镜头搭配，可按网上推荐选择                   |
| **APS-C（尤其索尼）生态** | 索尼 APS-C（如 A6700）有大量国产镜头：便宜、素质可用、可玩性高         |
| **全画幅选择心理因素**     | 全画幅常带来心理满足感，推荐 A7C2 的部分原因                     |
| **高性价比机身建议**      | Sony A7III 二手 7–8k，性能仍强；推荐镜头：腾龙 28–200、70–180 |
| **专业摄影师建议**       | 博主 Simon d’Entremont：二手机身 + 好镜头，镜头寿命大于机身      |
| **什么是单反？**        | 单镜头反光相机，光学取景 + 反光镜/五棱镜体积大，已逐渐退出市场，非单反（微单）是主流  |


|项目|APS-C|全画幅|
|---|---|---|
|传感器尺寸|小（22~24 × 14~16 mm）|大（36 × 24 mm）|
|画质|好，但高感表现略弱|更好，高感动态范围优秀|

|机身/镜头大小|小巧轻便|更大更重|
|价格|相对便宜|更贵|
