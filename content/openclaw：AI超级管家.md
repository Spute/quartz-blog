## 是什么

![[Pasted image 20260210141041.png]]
openclaw是一个AI助手，也称AI龙虾。适合各种操作系统的AI智能体，可以通过各种即时通讯软件（**支持 WhatsApp、Telegram、Discord、iMessage、飞书、企业微信、QQ 等**）发生消息来控制AI智能体帮你完成复杂各种任务。

官方文档：[https://docs.openclaw.ai/zh-CN](https://docs.openclaw.ai/zh-CN)

## 应用场景
| 场景分类        | 典型使用场景          | 可完成的事情                   | 核心价值               |
| ----------- | --------------- | ------------------------ | ------------------ |
| 远程自动化助理     | 不在电脑前，用手机指挥本地电脑 | 执行命令、处理文件、运行程序、回传结果      | 让本地电脑变成随身可控的“云端大脑” |
| 智能提醒        | 自然语言设置提醒和周期任务   | 临时提醒、定时任务、状态检查、消息推送      | 从死板定时器升级为“有判断力的助理” |
| 信息监控与自动简报   | 定期获取并整理信息       | 监控 GitHub 热点、生成中文简报、定时推送 | 信息获取自动化，降低认知负担     |
| 浏览器自动化      | 像人一样操作网页        | 打开网站、搜索、下载、解压、整理文件       | 解决复杂网页流程，绕开反爬限制    |
| 视觉感知 / 状态监控 | 远程查看电脑状态        | 实时截屏、桌面监控、执行过程回传         | 不在现场也能“看到电脑在干嘛”    |
| 跨平台聊天入口     | 国内外聊天工具统一入口     | WhatsApp、飞书等聊天控制与反馈      | AI 助理不绑定平台，随你所在而存在 |
| 办公自动化（邮件等）  | AI 当个人秘书        | 读取/总结邮件、发送邮件、邮件监控通知      | 大幅减少重复性办公操作        |
| MCP 第三方能力接入 | 动态接入外部服务        | 地图查询、路线规划、API 调用         | 通过 MCP 无限扩展能力边界    |
| AI 编程与开发助理  | 远程驱动本地编程工具      | 调用 Codex 写代码、生成项目、运行程序   | 用一句话完成真实开发工作       |
| 长期个人智能体     | 长期使用、持续交互       | 本地记忆存储、上下文召回、记忆更新        | 越用越懂你的“个人数字助理”     |
